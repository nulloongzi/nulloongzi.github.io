## 0. 컨셉 선언 — "누룽지의 눈으로"

- 사이트 = **서비스 소개가 아니라 배구에 대한 누룽지의 생각을 담는 편집샵.**
- 콘텐츠 포맷 = **인터뷰(Q&A).** 랠리 구조(서브→리시브→토스→스파이크→꽂힘)가 목차다.
- 연출 문법 = **하이큐 「쓰레기장의 결전」 켄마 시점.** 랠리 국면은 1인칭 POV, 시작(히어로)과 엔딩(공이 밥그릇에 담김)만 3인칭.
- 모든 결정의 체: **"이게 누룽지에게 DM하는 느낌인가?"** (따뜻함 > 화려함, 장난기 > 위엄)

## 1. 컬러

웹 CSS 변수와 3D 씬이 같은 값을 쓴다. 검정(#000) 사용 금지 — 선화·그림자·텍스트 전부 다크브라운 계열.

| 토큰 | HEX | 용도 |
|---|---|---|
| `cream` | `#FFF8E1` | 페이지 배경, 체육관 하늘/벽 밝은 면 |
| `yellow` | `#FAC710` | 브랜드 장식 (버튼, 언더라인, 배지) |
| `gold` | `#C9971C` | **타이포 강조 전용** (황갈색 — 크림 위 가독용 다크 골드) |
| `brown` | `#8D6E63` | 보조 텍스트, Q 라벨, 공 패널 라인 |
| `dark` | `#4E342E` | 본문 텍스트, 선화(아웃라인), 네트 포스트 |
| `urgent` | `#FF7043` | 안테나 스트라이프 등 극소량 포인트 |
| `zoneFront` | `#F6B83D` | 코트 전위(3m) 존 |
| `zoneBack` | `#FDE1A0` | 코트 후위 존 |
| `wood` | `#CFA672` | 체육관 마루 |
| `wall` | `#F3E2B8` | 체육관 벽 |

규칙: **강조는 gold, 장식은 yellow, 본문은 dark.** gold와 yellow를 같은 화면에서 같은 역할로 쓰지 않는다.

## 2. 렌더 스타일 — 애니메이션 질감 (3D)

- **셀 셰이딩**: `MeshToonMaterial` + 3단계 그라디언트 맵(4px 캔버스, `NearestFilter`). 명암은 부드러운 그라데이션이 아니라 **밴드로 끊어져야** 한다.
- **선화**: three.js `OutlineEffect` — 두께 `0.004`, 색은 다크브라운(`[0.24, 0.16, 0.13]`). 검정 아웃라인 금지.
- **조명**: 디렉셔널 1개 + 넉넉한 앰비언트. 사진적 요소(PBR 광택, 소프트 리얼 섀도, DOF, 블룸) 금지 — 만화는 빛을 그리는 것이지 계산하는 게 아니다.
- **환경**: 체육관 — 크림 벽 + 창문 빛(밝은 사각형) + 천장 보. 바닥은 마루(`wood`) 위에 존 색이 분리된 코트.
- **공**: 클래식 스월 무늬(캔버스 텍스처, 패널 라인 `#A58974`) + 톤 셰이딩. 사이트 전체(2D 폴백·OG·파비콘)에서 같은 공 얼굴을 쓴다.
- **캐릭터 배치 금지**: 코트에 3D 인물을 세워두지 않는다. 사람의 존재는 POV 손으로만 표현한다.

## 3. POV 연출

- **카메라 = 누룽지.** 히어로(코트 전경)와 엔딩(공이 그릇에 담기는 장면)은 3인칭, 랠리 국면은 아래 하이브리드 문법을 따른다.
- **하이브리드 컷 문법 (2026-08-05 확정)** — 순수 1인칭은 머리 위 찰나 동작을 못 담는다(사용자 검증: 점프 서브 아치는 측면에만 존재). 하이큐 켄마 시퀀스처럼 두 시점을 컷으로 오간다:
  - **공이 나에게 오는 순간 = POV** (리시브 낙하, 토스 올려다보기, 스파이크/서브 컨택)
  - **몸이 만드는 순간 = 측면 실루엣 컷** (점프 서브 아치, 스파이크 점프) — 단색 dark 실루엣 SVG 오버레이(내부 디테일 없음, 관절은 넉넉히 겹쳐 그림, `look-test.html`의 `#silhouette`), 배경은 3D 체육관 조망 + **수평** 스피드라인. 3D 캐릭터 금지 원칙은 유지 — 실루엣은 스타일이지 모델링이 아니다.
  - **찰나는 스크롤 슬로모로 늘린다**: 실루엣 컷에 긴 스크롤 구간을 배정해 공중 순간에 머물게 한다. 컷 시퀀스 예 — 서브: POV 토스 → 실루엣 아치(슬로모+타이포) → POV 컨택 → 볼캠 / 스파이크: 도움닫기 POV → 실루엣 점프 → POV 스윙+방사형 스피드라인.
- **손**: 3D 모델이 아니라 **2D SVG 일러스트 오버레이.**
  - 스타일: 흰 채움(`#FFFDF6`) + dark 선(5~6px, round join/cap), 그룹 `opacity: 0.72`.
  - **사람 손으로 그린다 (만화 장갑 금지)**: 손가락 길이 차등(중지 최장·소지 최단), 끝으로 갈수록 가늘어지는 테이퍼, 엄지는 손바닥 옆면에서 사선으로, 손바닥에 관절 크리즈 힌트 1줄(가는 선, opacity 0.45). 주먹은 말린 손가락 첫마디 능선 4개 + 아래를 사선으로 감싼 엄지.
  - 포즈 4종: 서브(공 든 손 + 당긴 손) / 리시브(모은 팔뚝 플랫폼) / 토스(양손 머리 위) / 스파이크(뻗은 손 + 당긴 주먹). 원본은 `look-test.html`의 `#open-hand`/`#fist-hand`/`#spread-hand`/`#platform` 심볼 — 재사용·미러링으로 변형한다.
  - **리시브 구도 확정 (2026-08-05, 사용자 제공 레퍼런스 — 실사 서브리시브 POV + 하이큐 리시브 컨택 프레임)**: 실제 1인칭에선 플랫폼이 화면 최하단에 겨우 걸리지만, **연출로 치팅해 프레임 안에 보이게 한다** (애니가 쓰는 방식). 모은 팔뚝 플랫폼(`#platform`: 맞잡은 손 + 엄지 2개, 아래로 갈수록 굵어지는 원근)이 하단 중앙에서 비스듬히(-12°) 들어오고, **플랫폼의 기울기 축이 낙하하는 공을 가리킨다**. 공은 상단에서 대각으로 낙하.
  - **스파이크/스파이크 서브 2비트 모션 (사용자 지정)**: ① 공을 향해 갈 때 = **왼손을 뻗어 공을 조준** (+오른팔은 백스윙으로 당김) ② 때리는 순간 = **오른손이 공을 때리는 스윙** (주먹이 아니라 오픈 팜). 타격 컨택 프레임에서만 손-공 접촉 허용 — 이는 겹침이 아니라 접촉이며, 공 완전 가시성 철칙의 유일한 예외다.
  - **토스 구도 확정 (2026-08-05, 사용자 제공 레퍼런스 기준 — 실사 세터 POV + 하이큐 극장판 세터 POV 프레임)**: 벌린 양손이 **하단 코너에서 화면 1/3 높이까지 크게** 들어오고(`#spread-hand`, 너클 볼록선·관절 크리즈·힘줄 힌트 포함), 손가락 끝은 공을 향한다. 공은 두 손 사이 중앙 상단. 천장에는 보 + 조명 열(흰 램프 + 옅은 헤일로)로 올려다보는 컷의 드라마를 만든다. 타이포는 상단 배치(공·손과 비겹침).
  - 진입: 화면 가장자리 밖에서 스크롤 진행률에 연동해 들어오고 빠진다. 항상 떠 있지 않는다.
- **공 완전 가시성 (철칙)**: 손 오버레이가 뜨는 동안 **공은 프레임 안에 온전히 보여야 하며**, 손·타이포와 겹치지 않는다. 스피드라인의 소실점 = 공. 시선의 주인은 항상 공이다.
- **스피드라인**: 스파이크 순간에만. SVG 방사형 집중선, dark 색, 전체 `opacity ≈ 0.55`, **중앙 40%는 비워** 시선이 공에 모이게.
- **완급 (켄마 시점의 핵심)**: 스크롤 구간 배분으로 시간을 조절한다 — 토스 구간은 길게(슬로모), 스파이크 구간은 짧게(가속). 균등 배분 금지.

## 4. 타이포그래피

- 서체: **Pretendard 단일.** 제목·강조 800, 본문 700, 라벨 700.
- **박스·카드 금지.** 텍스트는 장면 위에 직접 올린다. 가독성은 배경이 아니라 **카메라가 확보한다** — 텍스트가 뜨는 동안 카메라는 정지 또는 저속, 배경은 차분한 면(바닥·벽·하늘)을 보게 패스를 짠다.
- 구조 (인터뷰 한 문답의 위계):
  1. **Q 라벨**: `0.95rem / 700 / brown`, 접두 "Q. "만 gold.
  2. **본문 행**: `clamp(1.5rem, 6vw, 2.6rem) / 700 / dark`.
  3. **강조 행**: `clamp(2.2rem, 9.5vw, 4.2rem) / 800 / gold` — **각 국면의 핵심 가치 한 줄만.**
- 강조 행 지정 (국면별 고정):
  - 서브: "친구들이랑 배구를 할 수 있다는 것"
  - 이름: "'누룽지'로 불리고 있더라고요"
  - 리시브: "밥상에서 왔어요"
  - 토스: "아, 지도를 만들어야겠다"
  - 스파이크: "언제 어디서든."
  - 꽂힘: "그걸로 충분해요"
- `word-break: keep-all` 필수 (한글 단어 중간 줄바꿈 금지).
- 헤일로: `text-shadow`로 크림 발광(0 2px 18px + 0 0 40px, cream 계열)을 깔아 어떤 배경에서도 뜨게 한다.
- 등장: 행 단위 순차 등장(스크롤 연동). 글자 단위 스플릿은 강조 행에만 허용.

## 5. 모션

- 카메라 보간: 국면별 키프레임(pos/lookAt) + `lerp` 스무딩 계수 `0.09`. 회전은 lookAt 벡터 보간(짐벌락 방지).
- **모션은 콘텐츠를 감싼다, 지배하지 않는다** — 큰 카메라 이동은 텍스트가 없는 구간에서만.
- `prefers-reduced-motion`: 카메라 플라이트·손 오버레이·스피드라인 비활성, 텍스트는 전부 정적 표시.
- WebGL 실패/저사양: 2D 버전(`rally.html` 계열)이 폴백.

## 6. 기술 제약 (불변)

- **no-build 유지.** three.js와 애드온(OutlineEffect 등)은 `assets/vendor/`에 번들, `importmap`으로 연결. CDN 런타임 의존 금지.
- 텍스트는 전부 DOM — KO/EN 토글(`data-ko`/`data-en`) 확장 가능해야 한다.
- 텍스처·일러스트는 캔버스/SVG 코드 생성 우선. 외부 이미지 에셋은 최후 수단.
- 레포 전체가 Pages에 그대로 배포된다(`static.yml`) — 실험 파일도 공개됨을 전제로 커밋.
