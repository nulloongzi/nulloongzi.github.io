## 0. 컨셉 선언 — "누룽지의 눈으로"

- 사이트 = **서비스 소개가 아니라 배구에 대한 누룽지의 생각을 담는 편집샵.**
- 콘텐츠 포맷 = **인터뷰(Q&A).** 랠리 구조(서브→리시브→토스→스파이크→꽂힘)가 목차다.
- 연출 문법 = **볼캠(ball-cam).** 랠리 내내 카메라가 공 하나를 따라 코트를 난다. 시작(히어로)과 엔딩(공이 밥그릇에 담김)만 고정 3인칭. (2026-08-07 개정 — 이전의 켄마 시점 손 오버레이 문법은 폐기)
- 모든 결정의 체: **"이게 누룽지에게 DM하는 느낌인가?"** (따뜻함 > 화려함, 장난기 > 위엄)

## 1. 컬러

웹 CSS 변수와 3D 씬이 같은 값을 쓴다. 검정(#000) 사용 금지 — 선화·그림자·텍스트 전부 다크브라운 계열.

## 2. 렌더 스타일 — 애니메이션 질감 (3D)

- **셀 셰이딩**: `MeshToonMaterial` + 3단계 그라디언트 맵(4px 캔버스, `NearestFilter`). 명암은 부드러운 그라데이션이 아니라 **밴드로 끊어져야** 한다.
- **선화**: three.js `OutlineEffect` — 두께 `0.004`, 색은 다크브라운(`[0.24, 0.16, 0.13]`). 검정 아웃라인 금지.
- **조명**: 디렉셔널 1개 + 넉넉한 앰비언트. 사진적 요소(PBR 광택, 소프트 리얼 섀도, DOF, 블룸) 금지 — 만화는 빛을 그리는 것이지 계산하는 게 아니다.
- **환경**: 체육관 — 크림 벽 + 창문 빛(밝은 사각형) + 천장 보. 바닥은 마루(`wood`) 위에 존 색이 분리된 코트.
- **공 (2026-08-07 확정, 사용자 지정 레퍼런스): 유일한 실사 오브젝트 — 클래식 흰 배구공.** 흰 합성피혁(#F8F6F1), 클래식 18패널(세로 심 6열 + 열마다 엇갈리는 가로 심), 심 옆 스티치 점선, 패널별 미묘한 톤 차, 가죽 그레인 노이즈. `MeshStandardMaterial`(roughness 0.5) + 전용 보조광으로 부드러운 광택. **아웃라인 제외**(`outlineParameters.visible=false`). 근거 둘: ① 하이큐의 3DCG 문법 — 세계는 셀, 공만 리얼 ② 로고·OG·파비콘의 흰 공과 사이트 전체 공 정체성 통일. 옐로·블루(미카사풍)는 폐기.
- **사람 배치 금지**: 캐릭터도, 손 오버레이도 화면에 등장하지 않는다. 랠리는 오직 공의 여정으로 표현한다.

## 3. 볼캠 연출 (2026-08-07 전면 개정)

> 이전 판(켄마 시점 POV + 손 오버레이 + 실루엣 컷)은 폐기. 이유: 손 작화의 품질 변동성을
> 구조적으로 제거하고, 공을 유일한 주인공으로 승격. 폐기된 규칙·시안은 git 이력과
> `docs/design/`에 기록으로 남긴다.

- **카메라 = 공의 시점.** 랠리 전 구간에서 카메라가 공 뒤를 추적한다:
  - 위치 = 공 − 진행방향×거리 + 높이 + 측면 오프셋. 비트별 파라미터(거리 2.8~3.4 / 높이 0.9~1.8 / 측면 ±0.6~0.9)로 앵글 변화를 만든다. 측면 부호를 비트마다 교차해 좌우 변화를 준다.
  - 시선 = 공 + 진행방향×1.6 (공 너머의 코트를 본다).
  - 스무딩: 매 프레임 `lerp 0.1` (시네마틱 랙). 바닥 뚫림 방지 `y ≥ 0.55`.
- **랠리 궤적은 연속**: 토스업 → 서브 비행(네트 넘김) → 리시브(높이 올림) → 토스(세터 딥 후 재상승) → 스파이크(체공 후 급강하) → 바운드 → 밥그릇. 각 비트의 시작점 = 이전 비트의 끝점.
- **완급**: 섹션 높이 배분으로 조절 — 체공·상승(느림)에 텍스트, 낙하·강타(빠름)는 텍스트 없이. 스파이크 낙하 구간(t 0.55~0.95)에만 방사형 스피드라인(중앙 비움, opacity 0.5).
- **히어로/착지 예외**: 히어로는 고정 3인칭 전경, 착지는 고정 키프레임으로 풀아웃하며 공이 통통 튀어 밥그릇에 담기는 것을 지켜본다.
- **공 크기 가이드**: 화면에서 공 지름이 화면 폭의 25~45%를 오가게 (주인공답게 크되, 프레임을 침범하지 않게). 항상 온전히 보인다 — 공 완전 가시성 철칙은 유지.

## 4. 타이포그래피

- 서체: **Pretendard 단일.** 제목·강조 800, 본문 700, 라벨 700.
- **박스·카드 금지.** 텍스트는 장면 위에 직접 올린다. 가독성은 배경이 아니라 **카메라가 확보한다** — 텍스트가 뜨는 동안 카메라는 정지 또는 저속, 배경은 차분한 면(바닥·벽·하늘)을 보게 패스를 짠다.
- 구조 (인터뷰 한 문답의 위계):
  1. **Q 라벨**: `0.95rem / 700 / brown`, 접두 "Q. "만 gold.
  2. **본문 행**: `clamp(1.5rem, 6vw, 2.6rem) / 700 / dark`.
  3. **강조 행**: `clamp(2.2rem, 9.5vw, 4.2rem) / 800 / gold` — **각 국면의 핵심 가치 한 줄만.**
- 강조 행 지정 (국면별 고정):
  - 서브: "친구들이랑 배구를 할 수 있다는 것"
  - 이름: "'누룽지'로 불리고 있더라고요"
  - 리시브: "밥상에서 왔어요"
  - 토스: "아, 지도를 만들어야겠다"
  - 스파이크: "언제 어디서든."
  - 꽂힘: "그걸로 충분해요"
- `word-break: keep-all` 필수 (한글 단어 중간 줄바꿈 금지).
- 헤일로: `text-shadow`로 크림 발광(0 2px 18px + 0 0 40px, cream 계열)을 깔아 어떤 배경에서도 뜨게 한다.
- 등장: 행 단위 순차 등장(스크롤 연동). 글자 단위 스플릿은 강조 행에만 허용.

## 5. 모션

- 카메라 보간: 국면별 키프레임(pos/lookAt) + `lerp` 스무딩 계수 `0.09`. 회전은 lookAt 벡터 보간(짐벌락 방지).
- **모션은 콘텐츠를 감싼다, 지배하지 않는다** — 큰 카메라 이동은 텍스트가 없는 구간에서만.
- `prefers-reduced-motion`: 카메라 플라이트·손 오버레이·스피드라인 비활성, 텍스트는 전부 정적 표시.
- WebGL 실패/저사양: 2D 버전(`rally.html` 계열)이 폴백.

## 6. 기술 제약 (불변)

- **no-build 유지.** three.js와 애드온(OutlineEffect 등)은 `assets/vendor/`에 번들, `importmap`으로 연결. CDN 런타임 의존 금지.
- 텍스트는 전부 DOM — KO/EN 토글(`data-ko`/`data-en`) 확장 가능해야 한다.
- 텍스처·일러스트는 캔버스/SVG 코드 생성 우선. 외부 이미지 에셋은 최후 수단.
- 레포 전체가 Pages에 그대로 배포된다(`static.yml`) — 실험 파일도 공개됨을 전제로 커밋.
