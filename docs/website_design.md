## 0. 컨셉 선언 — "누룽지의 눈으로"

- 사이트 = **서비스 소개가 아니라 배구에 대한 누룽지의 생각을 담는 편집샵.**
- 콘텐츠 포맷 = **인터뷰(Q&A).** 랠리 구조(서브→리시브→토스→스파이크→꽂힘)가 목차다.
- 연출 문법 = **볼캠(ball-cam).** 랠리 내내 카메라가 공 하나를 따라 코트를 난다. 시작(히어로)과 엔딩(공이 밥그릇에 담김)만 고정 3인칭. (2026-08-07 개정 — 이전의 켄마 시점 손 오버레이 문법은 폐기)
- 모든 결정의 체: **"이게 누룽지에게 DM하는 느낌인가?"** (따뜻함 > 화려함, 장난기 > 위엄)

## 2. 렌더 스타일 — 애니메이션 질감 (3D)

- **셀 셰이딩**: `MeshToonMaterial` + 3단계 그라디언트 맵(4px 캔버스, `NearestFilter`). 명암은 부드러운 그라데이션이 아니라 **밴드로 끊어져야** 한다.
- **선화**: three.js `OutlineEffect` — 두께 `0.004`, 색은 다크브라운(`[0.24, 0.16, 0.13]`). 검정 아웃라인 금지.
- **조명**: 디렉셔널 1개 + 넉넉한 앰비언트. 사진적 요소(PBR 광택, 소프트 리얼 섀도, DOF, 블룸) 금지 — 만화는 빛을 그리는 것이지 계산하는 게 아니다.
- **환경**: 체육관 — 크림 벽 + 창문 빛(밝은 사각형) + 천장 보. 바닥은 마루(`wood`) 위에 존 색이 분리된 코트.
- **공 (2026-08-07 확정, 사용자 지정 레퍼런스): 유일한 실사 오브젝트 — 클래식 흰 배구공.** 흰 합성피혁(#F8F6F1), 클래식 18패널(세로 심 6열 + 열마다 엇갈리는 가로 심), 심 옆 스티치 점선, 패널별 미묘한 톤 차, 가죽 그레인 노이즈. `MeshStandardMaterial`(roughness 0.5) + 전용 보조광으로 부드러운 광택. **아웃라인 제외**(`outlineParameters.visible=false`). 근거 둘: ① 하이큐의 3DCG 문법 — 세계는 셀, 공만 리얼 ② 로고·OG·파비콘의 흰 공과 사이트 전체 공 정체성 통일. 옐로·블루(미카사풍)는 폐기.
- **사람 배치 금지**: 캐릭터도, 손 오버레이도 화면에 등장하지 않는다. 랠리는 오직 공의 여정으로 표현한다.

## 3. 볼캠 연출 (2026-08-07 전면 개정)

> 이전 판(켄마 시점 POV + 손 오버레이 + 실루엣 컷)은 폐기. 이유: 손 작화의 품질 변동성을
> 구조적으로 제거하고, 공을 유일한 주인공으로 승격. 폐기된 규칙·시안은 git 이력과
> `docs/design/`에 기록으로 남긴다.

- **카메라 = 공의 시점.** 랠리 전 구간에서 카메라가 공 뒤를 추적한다:
  - 위치 = 공 − 진행방향×거리 + 높이 + 측면 오프셋. 비트별 파라미터(거리 2.8~3.4 / 높이 0.9~1.8 / 측면 ±0.6~0.9)로 앵글 변화를 만든다. 측면 부호를 비트마다 교차해 좌우 변화를 준다.
  - 시선 = 공 + 진행방향×1.6 (공 너머의 코트를 본다).
  - 스무딩: 매 프레임 `lerp 0.1` (시네마틱 랙). 바닥 뚫림 방지 `y ≥ 0.55`.
- **랠리 궤적은 연속**: 토스업 → 서브 비행(네트 넘김) → 리시브(높이 올림) → 토스(세터 딥 후 재상승) → 스파이크(체공 후 급강하) → 바운드 → 밥그릇. 각 비트의 시작점 = 이전 비트의 끝점.
- **단계식 진행 (2026-08-07 확정, 스텝 컨트롤러)**: **자유 스크럽 금지, 네이티브 스크롤도 미사용.** 휠·스와이프·방향키는 "다음/이전 비트" 신호일 뿐(스텝 쿨다운 450ms, 휠 임계 55, 스와이프 임계 45px), 이동은 시간 기반으로 재생된다(속도 1.15비트/초, 목표 근접 시 감속) — 부드러움은 UA 스냅이 아니라 이 비행 이징이 담당한다. 우측에 진행 도트 7개(클릭 점프 가능). **정착 = 구간 완주(t=1) 상태**이며, 비트마다 정착 카메라(SETTLE 키프레임)가 추적캠에서 블렌드(t 0.72~1)되어 설계된 구도를 보장한다.
- **스파이크 정착 = 프리즈 프레임**: 바닥에 놓인 공(죽은 순간)이 아니라 **낙하 직전 공중 정지 컷** — 방사 스피드라인을 켠 채 멈춘다. 마지막 낙하는 착지 비트의 도입부로 이어진다.
- **밥그릇 비율**: 공이 그릇 입구를 가득 채우는 로고 비율 (그릇 스케일 0.58).
- **이동 중에는 아무 것도 띄우지 않는다**: 텍스트는 정착한 비트에서만, 행 단위 스태거(0.15s + 행당 0.28s)로 등장한다. 공-텍스트 비겹침은 정착 컷 기준으로 검수한다.
- **완급**: 비행 자체가 시간 재생이므로 구간 길이가 곧 완급. 스파이크 낙하 통과(t 0.5~0.95)에만 방사형 스피드라인(중앙 비움, opacity 0.5).
- **히어로/착지 예외**: 히어로는 고정 3인칭 전경, 착지는 고정 키프레임으로 풀아웃하며 공이 통통 튀어 밥그릇에 담기는 것을 지켜본다.
- **공 크기 가이드**: 화면에서 공 지름이 화면 폭의 25~45%를 오가게 (주인공답게 크되, 프레임을 침범하지 않게). 항상 온전히 보인다 — 공 완전 가시성 철칙은 유지.

## 4. 타이포그래피 — 에디토리얼 좌측 컬럼 (B안, 2026-08-07 확정)

> 조사 근거: 한글 웹 타이포 기본기(KRDS·행간 1.5~1.75·대형 텍스트 자간 조임·줄길이 한글 25~40자),
> 2026 에디토리얼 폰트 트렌드(굵기·크기 대비가 세련됨을 만든다, 색 의존 강조는 지양),
> 스크롤 사이트 텍스트 패턴 3계열(Apple 중앙 스티키 / NYT 사이드 컬럼 / WebGL 대형 타이포).
> A(Apple식 중앙)·C(세리프 강조) 비교 시안은 `docs/design/typo-3way.png`. **B 채택.**

- 서체: **Pretendard 단일.** 세리프 도입은 보류(C안 — 톤이 에세이 쪽으로 기움).
- **레이아웃**: 좌측 컬럼 — `left: 8vw`, `top: 13vh`, `width: min(78vw, 34ch)`, 좌측 정렬 고정. 우측은 공의 자리로 비운다.
- **위계 3단**
  1. **캡션 라벨**(`.lbl`): `0.7rem / 700 / brown`, `letter-spacing .2em`, **위쪽 괘선**(1.5px, brown 35%) + 상단 패딩 12px. 잡지 캡션 문법.
  2. **본문**(`.body-line`): `1.02rem / **400** / #5C463D`, `line-height 1.85`, `letter-spacing -0.005em`, 문단 간격 16px. **굵은 본문 금지.**
  3. **강조**(`.hit`): `clamp(1.9rem, 7.4vw, 2.9rem) / 800 / dark`, `line-height 1.32`, **`letter-spacing -0.035em`**(대형 한글은 반드시 조인다), 옐로 **형광펜 밑줄**(`linear-gradient(transparent 68%, rgba(250,199,16,.55) 68%)` + `box-decoration-break: clone`). **글자색을 gold로 칠하지 않는다** — gold/yellow는 악센트로만.
- **가독성 확보 = 스크림**(헤일로 금지): `#scrim`에 `linear-gradient(100deg, cream .92 → .72(26%) → .22(48%) → 0(66%))`. 텍스트 뜰 때 함께 페이드 인.
- `word-break: keep-all` 필수. 강조 행은 `<br>`로 줄바꿈을 의도적으로 제어한다.
- **등장**: 요소 단위 스태거 — `.rv` 클래스에 `0.12s + 인덱스×0.13s` 지연, 16px 상승 + 페이드. 정착한 비트에서만.
- **공 위치는 수식으로 보장**: 정착 시 카메라를 역산해 공을 항상 **NDC (0.36, −0.30)**(우하단 1/3)에 놓는다 — 비트별 구면 배치(거리·yaw·pitch)만 지정하면 화면 좌표는 솔버가 맞춘다(`solveSettle`). 텍스트 컬럼과 절대 겹치지 않는다.
- 강조 행 지정 (비트별 고정):
  - 서브/토스업: "친구들이랑 배구를 할 수 있다는 것."
  - 볼 플라이트: "'누룽지'로 불리고 있더라고요."
  - 리시브: "밥상에서 왔어요."
  - 토스: "아, 지도를 만들어야겠다."
  - 스파이크: "언제 어디서든."
  - 착지: "그냥 누룽지가 궁금했다면, 그걸로 충분해요."

## 5. 모션

- 카메라 보간: 국면별 키프레임(pos/lookAt) + `lerp` 스무딩 계수 `0.09`. 회전은 lookAt 벡터 보간(짐벌락 방지).
- **모션은 콘텐츠를 감싼다, 지배하지 않는다** — 큰 카메라 이동은 텍스트가 없는 구간에서만.
- `prefers-reduced-motion`: 카메라 플라이트·스피드라인 비활성, 텍스트는 전부 정적 표시(스크림도 해제).
- WebGL 실패/저사양: 2D 버전(`rally.html` 계열)이 폴백.

## 6. 기술 제약 (불변)

- **no-build 유지.** three.js와 애드온(OutlineEffect 등)은 `assets/vendor/`에 번들, `importmap`으로 연결. CDN 런타임 의존 금지.
- 텍스트는 전부 DOM — KO/EN 토글(`data-ko`/`data-en`) 확장 가능해야 한다.
- 텍스처·일러스트는 캔버스/SVG 코드 생성 우선. 외부 이미지 에셋은 최후 수단.
- 레포 전체가 Pages에 그대로 배포된다(`static.yml`) — 실험 파일도 공개됨을 전제로 커밋.
